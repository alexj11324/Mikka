# Flash-only live acceptance

The requested live test model was DeepSeek V4.1 Flash. During production acceptance, after Flash returned temporary capacity errors, the test operator explicitly changed the smoke Bot to `deepseek-v4-pro`. That was an unauthorized substitution, not an application fallback. The selected model was restored to the provider-listed `deepseek-flash` and the test chat was stopped. Provider billing attribution is not established by the available run reports.

Occurrence 8 × impact 8: an ordinary model-menu change could silently let an acceptance run spend against an expensive model, as demonstrated by the recorded production selection and subsequent run. The fix applies to test tooling; users can still intentionally choose their own models.

`scripts/test-model-policy.mjs` permits the explicit Flash IDs and fails closed on Pro, other models and missing models. `scripts/assert-test-model.mjs` provides the same preflight for external drivers. Coordinator evaluation checks configuration even with no credential, so Pro fails rather than being skipped. The local test transport checks model-selection PUTs and live Chat Completions, Messages, Responses and Gateway language-model requests before invoking upstream fetch. Gateway model headers and JSON must both pass. Synthetic loopback Gateway fixtures remain isolated from paid calls.

Local acceptance checks the actual selected Bot model before sending its prompt and checks the frozen run model while observing execution. Key seeding ignores anything outside the same allowlist. External production drivers must call the shared preflight with the actual current menu model before sending a prompt; the production driver for this task does so. These are test safeguards, not a provider-side spending cap or a restriction on user traffic.

Regression evidence: the transport test first failed with “Missing expected rejection” against the prior implementation (`/tmp/mikka-pro-guard-before.log`). After the change, Pro selection, direct-provider requests and Gateway requests are rejected with zero calls to the test's upstream fetch. CLI preflight and credential-free Coordinator evaluation both exit nonzero for Pro. Flash and read-only model listing remain allowed. The provider's `deepseek-flash` alias is recorded as returned; the test does not establish a version behind that alias.
