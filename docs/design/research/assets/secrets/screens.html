说明（给评审，不是界面文案）

  • 一个页面「密钥与登录」，顶部切换「我的 / Mikka 团队」。侧栏的「账号 › 密钥与登录」和「工作区 › 密钥与环境」都打开这一页，只是默认停在不同的一侧；侧栏高亮跟着切换走。
  • 筛选：我的 = 全部 / 密钥 / 网站登录；工作区 = 全部 / 工作区 / 仓库。
  • 类型只有「密钥」和「网站登录」。「环境变量」改成更多控制里的「在输出里遮住」开关，默认打开（Alex ⑤）；关掉的行在类型旁标「不遮住」。
  • 没有「每次使用前问我」（Alex ②）。
  • 04：照 Devin「Safer Secret Defaults」，存到工作区前确认一次；成员新建时默认「仅我」。
  • 05：按行报结果，保留名称（PATH 等）跳过；值只用圆点显示。
  • 06/07：网站登录不能选工作区（密码箱只属于个人）；编辑时网站和账号不能改，只能改密码、两步验证和说明；值永远不回显。
  • 09：成员能看工作区和仓库的名称、类型、说明；工作区那几行是 🔒，不能改；成员新建时范围只有「仅我 / 仓库」。不写解释句子（R-40）。
  • 值只写不读，和 Devin 一样（Alex）：存进去后能用、能替换、能删除，不能查看或复制。👁 只在输入时看自己正在输的内容。
