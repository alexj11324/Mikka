# 新建任务、新建 Bot 照 Capy 的新建窗口做

Alex，2026-11-15：「去加吧，另外 mikka 新建 issue 的窗口也是能换的」。

## 决定

参照 Capy 的 New issue 和 New Captain 窗口做。只学布局和交互，不用 Capy 的代码、头像和文案。

**新建任务**

- 窗口仍是 affectUI Kanban 的 `CreateWindow`（标题栏、遮罩、⌘↵、Esc、底栏），里面的布局改了，这是对「原样使用，只换数据」的一次批准例外。
- 窗口里只有一列：没有输入框外框的大标题（可选，不填由 Bot 起；回车跳到描述）、附件卡片、描述，然后是一排小按钮：附件、创建方式（页面允许选择时）、机器、交给、Agent 配置。右侧的详情栏去掉了。
- 底栏有 Capy 的「继续新建」（Create more）开关：打开后，创建成功只提示「任务已创建」，窗口留着并清空（附件一起清空），光标回到标题；机器、交给、配置都保留，页面的任务列表随即刷新，新卡片出现在窗口后面。
- 窗口没有副标题，从项目页打开时才显示「项目：…」。

**新建 Bot**

- 在大头像、名字、形状和颜色旁边加一栏详情，就像 Capy 新建 Captain 时的设置行：「模型」（选项和对话里的模型菜单一样，Bot 建好后再保存选择）、「仓库」（默认用工作区设置，可以选「不用仓库」）。
- 用模板自带的 `CreateRow` 和菜单，没有改样式。窗口没有副标题（R-40）。
