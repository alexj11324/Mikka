# TestFlight build with over-the-air updates and 重启以更新

- Date: 2026-10-31
- Source: Alex, relayed by the coordinator: 「那你推就TestFlight吧」; 「有更新的话，我们提前缓存好，然后设置一个按钮…点一下就可以更新」
- Rule: —
- Replaces: —

The iOS app ships through TestFlight (EAS build, `production` profile) and
takes JavaScript changes as EAS Updates, so Alex installs once. A push to
main that touches `apps/mobile` or `packages/protocol` publishes to the
`production` channel; a pull request publishes to branch `pr-<n>`. The
runtime version is the native fingerprint, so an update never reaches a build
whose native code differs; a native change needs a new TestFlight build.

The app checks for an update at launch and whenever it returns to the
foreground, and downloads it in the background. Once one is downloaded, the
drawer shows a row after 任务: a circle-with-down-arrow icon and
「重启以更新」. Tapping it restarts into the new version. With no update
downloaded the drawer shows nothing extra.
