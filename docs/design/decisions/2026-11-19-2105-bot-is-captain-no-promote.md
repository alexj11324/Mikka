# Bot 对应 Capy 的 Captain，但不做 Promote / Demote

2026-11-19。Bot 设置对照 Capy Captain（Figma 第 23–26 节）时 Alex 的决定。

## 决定

- Mikka 的 Bot 就是 Capy 的 Captain：任务可以指派给 Bot，自动化的 Runs in 可以选 Bot 的线程，Bot 有 Environment、运行位置、默认派活位置、Alias、成员与订阅。
- **不做** Capy 的 Promote to Captain / Demote to thread / Promote folder。Bot 跑 Mikka 自有 harness **EVE**，普通线程跑 Claude Code / Codex，两者运行时不同，互转现在不合适。
- Bot 侧栏右键菜单保留 Mikka 独有的四项：Copy link、Mute、View all threads、Hide；Capy 有的 Share、Move to 补上。
- 自动化原来单独的「Hand to」一行并入 Runs in：A new thread each run / One standing thread / An existing thread（可选 Bot）。
