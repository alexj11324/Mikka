# A thread's badge says its group

- Date: 2026-11-02
- Source: the coordinating session, on a report relayed from review (「已完成线程的标题栏和列表里，状态图标是空心圆，旁边标签却写『已完成』，两者不一致」), choosing option A: 「徽标的图标和文字都跟分组走，列表、卡片和徽标完全一致……『未判定的 succeeded 不能看起来像已解决』是 R-52 的核心。」
- Rule: R-52
- Superseded in part by: [2026-11-07-2300](2026-11-07-2300-one-conversation-per-task.md) (an attempt shows its own result icon; only the task can show the hand).
- Replaces: —

The state badge of a thread (an open thread under its title, a row of a
task's 线程, the card of a thread chip) showed the run's raw status
(运行中, 已完成, 已停止, 失败…) beside an icon that follows the thread's group,
so a finished run that nobody judged read 已完成 next to 等待你's hand.

The badge now shows the group's icon and word, the same as the list it sits
in: 进行中, 等待你, 受阻, 空闲, 已解决. The colours follow the group too.
Only a stop on its way says 正在停止…. R-52 stays as it is: an unjudged
finished run never looks resolved.
