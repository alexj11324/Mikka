# A personal workspace keeps Bot 与 Agents

- Date: 2026-11-02
- Source: Alex, relayed by the coordinator session: 「个人工作区也要保留『Bot 与 Agents』设置项。个人工作区和团队工作区只差团队相关的内容（成员、共享额度、共享工作等），Bot 和 Agent 两边都要有。」
- Rule: R-26
- Superseded in part by: [2026-11-02-0216](2026-11-02-0216-personal-workspace-has-workspace-settings.md) (常规 and 密钥与环境 show in a personal workspace too)
- Replaces, in part: [2026-11-01-2310](2026-11-01-2310-personal-and-team-workspaces-apart.md), level 3's 「Bot 与 Agents」, which listed it as a team setting

A personal workspace's settings show 「Bot 与 Agents」 (defaults for where,
with which agent and which model the person's bots run, and the rule labels),
as a team workspace's do. The two kinds differ only in what concerns the team:
成员, 团队, 团队权限, 密钥与环境, 审计日志, shared credits and shared work. The
archived bots of people who left (an admin takes one over) are a team's and
stay in a team workspace only.

重新播放引导 is the person's too: it moves from 常规 (a team setting) to 偏好设置,
so every workspace, a personal one included, shows it.
