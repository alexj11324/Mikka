# 自动化：每次运行新建任务，或追加到同一个任务

Alex，2026-11-15：自动化可以选每次运行新建任务，还是追加到同一个任务里接着做（和 Codex 的自动化一样可选）。延续 [2026-11-15-1337](2026-11-15-1337-automations-v1.md)。

## 决定

- 设置里加「每次运行」：**新建任务**（默认，和以前一样）或 **追加到同一个任务**。只用于交给 Bot 的自动化。
- 选了追加：第一次运行照常新建任务并派发；之后每次运行都以创建者身份，把要求（和触发它的事件）作为一条新消息发进那个任务的线程，就像创建者自己在任务里打字一样。线程还在跑就排进去；已经结束就在同一个线程里接着跑一轮。重试不会重复发送。
- 那个任务的 Bot 还没开始干活时，这次运行稍后重试，不会再建第二个任务。
- 那个任务被删除，或者不再在这个工作区里：运行失败，自动化自动暂停并写明原因（「追加的那个任务已经不在了」），和失去权限时一样。
- 用量里的花费按任务算：每个任务只算一次，追加的运行用掉的也算在那个任务里，记在花费发生那天。

**运行身份**：仍以创建者身份运行。工作区的所有者或管理员可以「接手」，见 [2026-11-15-1840](2026-11-15-1840-automation-take-over.md)。
