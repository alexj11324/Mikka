# beUI is the one component family on web and mobile

- Date: 2026-10-31
- Source: Alex, relayed by the coordinator: 「你把 BEUI 的那些组件全都装进…打包进去…磨刀不误砍柴工」
- Rule: —
- Replaces: —

Web and the iOS app use one component family, beUI: its web components in
`components/agents/` and `components/motion/`, and beUI Native in
`apps/mobile/components/beui/`. AI Elements is not used.

All 38 free beUI Native components (Actions, Forms, Navigation and lists,
Motion and AI agents) are vendored into the app now, with the native modules
they need (Reanimated, Worklets, Gesture Handler, Skia) and Uniwind. Those
modules ship in the next TestFlight build, so later screens that use the
components go out as over-the-air updates (2026-10-31-2010-ota-updates). The
existing StyleSheet screens are unchanged. The beUI light theme tokens take
the app's colours from `lib/theme.ts`. Nothing is copied from beUI Pro.
