# Self-hosting becomes community-maintained

**Accepted November 20, 2026 by Alex.**

Mikka maintains Mikka Cloud. Self-hosting is community-maintained. Remove
dedicated self-hosted CI, including compatibility and screenshot checks, and
end automatic self-hosted image and stable release publication. Keep shared
backend, database, daemon, and official application verification with their
existing owners.

People running their own server can use existing release images, Compose
files, and host tools. See the [community self-hosting guide](../../self-hosting.md).
