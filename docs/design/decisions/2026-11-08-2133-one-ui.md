# There is one UI

- Date: 2026-11-08
- Source: Alex, 2026-11-08, issue #1646 (comments at 19:38 and 21:33 UTC). 「只有一套界面设计」; 「参照 LobeHub：自始至终只有一套界面，就叫"UI"，没有"托管版界面"和"社区版界面"之分」; 「修界面问题时，直接改这个页面现在代码所在的位置」; 「公开仓库只要求能编译；私有仓库里的东西原地不动」.
- Rule: —
- Replaces: the UI freeze in issue #1646 (no UI changes in this repository, smallest-public-change approvals, community screenshots), the "community UI vs hosted UI" framing in issues #1646 and #1557, and the line "The open-source repository's interface stays as it is" in [2026-11-06-2000](2026-11-06-2000-hosted-ui-overlay.md).

Mikka has one UI, called "the UI". There is no hosted UI and no community UI.

- **Fix the UI where its code lives.** A page's code is either in this
  repository or in the private `alexj11324/mikka-hosted-ui`. Change it there.
  Don't add a slot only so a fix can live somewhere else, and don't move code
  between the repositories for this.
- **Paid components are a tool, not a requirement.** Use BoardUI Pro, affectUI
  or beUI Pro where they are already used, or where they are clearly the right
  component. A page doesn't need a slot or a paid component to be part of the
  UI.
- **Paid component source never enters this repository or its image.** That
  includes BoardUI Pro, affectUI and beUI Pro component source, registry
  output, kits and bundles. Official builds bring it in from
  `mikka-hosted-ui` ([`docs/ui-overlay.md`](../../ui-overlay.md)), and the
  existing release audits keep checking that the public output doesn't carry
  it.
- **The public build only has to compile.** Without `mikka-hosted-ui`, the
  build uses the default components in this repository. Nobody designs,
  screenshots or reviews a separate open-source look.
- **One set of screenshots.** UI changes are checked with screenshots of a
  local production build of the official UI (this repository plus
  `mikka-hosted-ui`), light and dark.
- **Official apps connect to any server.** Self-hosters run the server, API
  and daemon, and use the official web, desktop or iOS app with their own
  server ([2026-11-06-2300](2026-11-06-2300-desktop-connects-to-self-hosted-servers.md)).

Official builds resolve their interface from `mikka-hosted-ui`. The public server image ships the account and handoff pages. The transitional community workspace option was retired under [#1972](https://github.com/alexj11324/Mikka/issues/1972).
