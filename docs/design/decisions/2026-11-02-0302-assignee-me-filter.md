# 负责人 我 matches me and my own bots and Agents

- Date: 2026-11-02
- Source: the coordinating Claude session, 2026-11-02, deciding under Alex's instruction to settle such questions from HCI principles, after the usability review (findings D7)
- Rule: —
- Replaces: —

The board filter 「负责人 我」 matches tasks assigned to the person and
tasks held by the person's own bots or Agents: work handed to my bot is my
work, and the default board must show it. Tasks the person created are a
separate filter, 「我创建的」.
In the review the default 「负责人 我」 also matched tasks the person
created, so the column counts were the same with it on or off.
