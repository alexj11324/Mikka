# Bot sidebar threads open in the main chat

On Web and Electron, selecting a conversation thread under a Bot opens it in
the main chat and highlights its sidebar row. Opening an independent review or
verification from within that conversation shows the child in the right pane.
The main conversation stays open when the child closes.

When the Bot lists the main conversation for a task, its independent checks
appear inside that conversation. A check with no main conversation in the
Bot's list still has its own sidebar entry.

Links copied from a Bot's sidebar open the same main chat. Existing links to
threads in the right pane retain their destination.
