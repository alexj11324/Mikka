# 订阅只给自己用

2026-11-17：用户决定，Claude 和 Codex 订阅只给订阅的主人用，成员之间不再共享订阅。

## 决定

- 一项订阅只跑它主人自己的 Bot、Coordinator 和任务。其他成员的 Bot 和任务不能用，也不出现在他们的模型菜单里。
- 「分享给团队成员」不再用于订阅：设置里的开关、「可用的成员订阅」行和对应的服务端路径都去掉了。API Key 的团队分享不变，团队权限里管理员的开关仍然管 API Key 的分享。
- 主人自己的订阅照旧可以在他所在的每个工作区使用，不需要任何开关（[2026-11-01-2240](2026-11-01-2240-own-credentials-always-usable.md)）。
- 迁移 `20261117140000_subscriptions_owner_only` 删除旧的分享记录。Bot 对话里如果还选着同事的订阅，这个选择会被清掉，对话会请主人选自己的模型。
- 派到指定电脑的任务必须能确定用哪个 Agent：要么点名，要么对话的模型属于该电脑上唯一对应的 Agent，要么这台电脑只有一个 Agent。否则派发时立即返回 `agentRequired`，不会悄悄退回默认 Agent。（被 [2026-11-17-1800](2026-11-17-1800-one-agent-per-thread.md) 收紧：每次新派发都必须点名 Agent。）

取代 [2026-11-15-1900](2026-11-15-1900-models-on-gateway-like-capy.md) 规则 3 里的「工作区共享的连接」（来源顺序现在是：自己的连接 → Mikka 额度）、[orchestration.md](../orchestration.md) §2 第 2 步（「其他成员分享的凭据」）和 其他文档里关于团队共享订阅的描述。
