# 等待你 is the first group of every thread list

- Date: 2026-11-02
- Source: the coordinating Claude session, 2026-11-02, deciding under Alex's instruction to settle such questions from HCI principles, after the usability review (findings D6, T2): 「需要用户行动的优先」
- Rule: R-52
- Replaces: the group order in [2026-11-01-1250](2026-11-01-1250-five-thread-groups.md)

Every thread list, web and phone, now starts with 等待你（N）: 等待你, 进行中,
受阻, 空闲, 已解决. Threads that need the person's action come before
threads that only report progress (heuristic: visibility of system status;
the work that needs the user first). In the review, 等待你 began about
2100px down 全部线程, under 26 running threads. 已解决 stays collapsed by
default. The count on the top-bar 全部线程 entry is the 等待你 count
([information-architecture.md](../information-architecture.md)).
