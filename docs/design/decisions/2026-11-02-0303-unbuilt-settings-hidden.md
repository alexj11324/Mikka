# Settings that are not built are not shown

- Date: 2026-11-02
- Source: the coordinating Claude session, 2026-11-02, deciding under Alex's instruction to settle such questions from HCI principles, after the usability review (findings D8)
- Rule: R-40
- Replaces: —

A setting whose feature is not built does not appear. About 16 rows in a team
workspace's settings looked live, did nothing when clicked, and explained
themselves only in a screen-reader sentence. They are hidden until the
feature exists, rather than shown disabled: a control that cannot be used is
filler (R-40).
