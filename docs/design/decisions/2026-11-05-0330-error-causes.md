# Keep the cause, give a sub-code, give copy for every surfaced code

- Date: 2026-11-05
- Source: Alex, 2026-11-05, after a run ended with the raw `subscription_local_runtime_unavailable` as its summary: 「很多时候都会遇到这种问题，不同的原因都混到了同一个错误码上…很多其他地方都有问题」
- Rule: R-42 (copy lives in `messages/*.json`) applies to error codes too
- Replaces: —

An error that a different failure can also produce must retain the actual cause. Current enforcement lives in `scripts/error-cause-policy.mjs` and the user-error registry; the original dated audit was removed from the working tree during documentation consolidation.

- **One stable code, one detail, the cause.** Throw
  `CodedError(code, { detail, cause })` from `@mikka/protocol/coded-error`, or
  a type that extends it (`SubscriptionRefusal`, `PaidResourceError`,
  `FactoryError`). The code stays what the UI and other code match on. The
  detail names the failed check and comes from a closed set (a union type, or
  the code's list in the registry). The message is `code (detail)`, the shape a
  run's stored error already has, so the detail survives into
  `agent_runs.error` and `report.summary`.
- **Log by name and code, never by message.** `logCodedError` writes one
  structured line: code, detail, and the cause chain by name and code. A
  cause's message can carry stderr, a response body or a credential, so it is
  never logged. When even keeping the cause is unsafe (a JSON parse error quotes
  the body), drop it and say why in a `// error-cause: <reason>` comment.
- **Copy for every code a person can see.** A code that reaches a run's
  failure line or summary is listed in
  `packages/protocol/src/user-error-codes.ts` with its details. Each one has
  words under `RunErrors.<code>.default` and `RunErrors.<code>.<detail>` in
  both catalogues, written to copy.md (what happened; what to do when it is
  outside the screen). The thread shows those words; the raw code is only
  under 详情. Subscription refusal codes keep the chat's
  `Coordinator.subscriptionRefusal.*` words. Text from an agent or a provider
  is shown as it is.

Enforced by `scripts/error-cause-policy.mjs` (`pnpm lint:ui`,
`pnpm test:ui-policy`). It fails when a registered code or detail has no copy
in either catalogue, when `RunErrors` has words for something not registered,
and when a `catch` throws a new error without handing on the caught one
(`{ cause: error }`, or the error as a helper's argument). The drops that were
already there are counted per file in `droppedCauseAllowlist`. That list only
shrinks, as the polling allowlist does.
