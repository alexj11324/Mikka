# Components: what to use, what not to bring back

Pick the component from the "Use" table. If nothing fits, use reUI, then
shadcn (`components/ui/`, including components nothing imports yet), then
`components/motion/` or the OpenUI catalog, and only then write a new one
and add it here in the same PR. This applies to designs in Figma as much as
to code: a frame draws the existing component as its code renders it, never
a look-alike (R-90). `pnpm lint:ui` blocks hand-built UI that a library
component covers.

Inside a paid block or component (BoardUI Pro, affectUI, beUI Pro, in the
hosted layer) nothing here replaces its parts: it keeps its own icons,
avatars, controls and look, and only data and text change
([2026-11-09-0050](decisions/2026-11-09-0050-paid-blocks-as-shipped.md)).

## Build selection

The components below include the default UI slots. Official builds fill some
slots from `mikka-hosted-ui` ([UI slots](../ui-overlay.md)), and `@ui-slot/*`
resolution decides which implementation ships. There is one UI
([decision](decisions/2026-11-08-2133-one-ui.md)): the defaults only have to
compile. The accepted
navigation lists tasks and shows each task as one conversation
([task lists](decisions/2026-11-07-2045-tasks-only-threads-inside.md),
[conversation](decisions/2026-11-07-2300-one-conversation-per-task.md)); public
thread-list fallbacks remain in source. Check the selected layer and revision
before claiming implementation parity.

## Historical chat compatibility

`legacy-chat-archive.tsx` displays saved pre-retirement chat records read-only.
It has no composer, generation request or retry execution. Historical replies
use an accessible static projection: every saved Accordion item and Tab is
expanded as readable text; live ComputerCard and action components are never
mounted. The body is selectable and remains in the accessibility tree. The standalone `agent-panel`, `agent-chat`, `agent-composer`, `agent-welcome`
and `agent-response` generation host components are retired. Shared `agent-*`
rendering primitives used by the current Bot are retained; their internal names
are not a separate product entity.

## Changing this list

Adding a component, retiring one, or moving one between the tables is a
change to this file in the same PR. If you delete a "Do not use" component,
remove its row.
