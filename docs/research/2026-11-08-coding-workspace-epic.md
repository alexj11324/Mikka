# Epic 草稿：代码工作区（改动 · 文件 · 预览）

> 这是 issue 草稿，等协调会话审阅后再建 issue，现在不要创建。

## 目标

一个改代码的任务，用户在 Mikka 里就能完成：看改动、看文件、看检查、写行内评论、交回给 Agent。不用跳到 GitHub 或编辑器。

平常的布局不变：图标栏、Bot 列表、聊天、右侧任务栏。代码任务在它那一个对话旁边多出「工作区」：
- 标签：对话 · 改动 · 文件 · 预览。
- 审阅模式下，工作区铺满，左侧窄条保留任务的对话。

## P0

### P0-1 每个代码任务都有「改动」

- 机器运行中，读机器上的工作区改动；机器回收后，依次退回检查点的 diff、PR 的 diff。
- 有 PR 以后，改动仍在 App 内显示，「在 GitHub 打开」只是次要链接。
- 大改动按文件分页加载，不再整块提示「太大」。
- 范围切换：全部 / 第 N 次尝试 / 某个提交，默认「全部」。
- 支持单栏和并排，逐个文件标记已看。

验收：
- [ ] 运行中、已结束（有检查点）、已开 PR 三种状态都能看到改动，且内容与 git 一致。
- [ ] 没有检查点的代码任务也显示「改动」标签。
- [ ] 超过 8 MiB 的改动能按文件打开，不报错。
- [ ] 切到「第 2 次尝试」只显示这次尝试的改动。
- [ ] 改动刷新走实时推送，不加轮询（`scripts/polling-policy.mjs` 通过）。

### P0-2 文件树和只读源码

- 「文件」标签：仓库文件树、⌘P 快速打开、只读源码。被改过的文件有标记。

验收：
- [ ] 能浏览任务仓库的完整文件树，打开任意文本文件看源码。
- [ ] ⌘P 能按文件名找到文件。
- [ ] 不显示密钥文件（决定 0240）。队友打开也只能读。

### P0-3 行内评论和「发给 Agent」（Web 和 iPhone）

- 在 diff 的行上写评论，攒进批次条「N 条评论 · 失败检查」，点「发给 Agent」发出。
- 发出后，这一批作为一条消息出现在任务对话里（「你：N 条评论」，带 `文件:行` 引用）。Agent 的修复回到同一个对话，改动自动刷新。
- 任务对话的输入框不放评论附件。
- iPhone 同样有：长按一行写评论，悬浮批次条，评论 sheet，「发给 Agent」。

验收：
- [ ] Web：给两行写评论，再附上一个失败检查，点「发给 Agent」；任务对话里出现一条带两处引用和检查名的消息，Agent 开始下一轮。
- [ ] iPhone（TestFlight）：同样的流程能完成，消息在 Web 端也看得到。
- [ ] 刷新页面后，未发送的评论还在。
- [ ] 队友（只读）看不到「发给 Agent」，也不能写评论。
- [ ] 两条订阅路径各跑一次真实任务：Claude Code 用 `claude-haiku-5-5`，Codex 用 `gpt-6-luna`。

### P0-4 检查和 PR 放在改动旁边

- 改动标签顶部显示 PR 号和状态、失败的检查、通过的检查数。
- 失败的检查可以「查看日志」，也可以「附到评论」（附进批次，不自动发送）。
- 与 #1502 共用数据和组件。

验收：
- [ ] CI 失败时，改动顶部显示失败的检查名，日志能打开。
- [ ] 「附到评论」后，批次条显示「· 失败检查」，发送的消息里带检查名和失败摘要。

### P0-5 审阅模式

- 用 ⤢ 按钮或 ⌘⇧B 进出。Esc 只在焦点不在输入框时退出。切换瞬间完成，不加动画（R-37）。
- R-51 例外：只有工作区的标签可以有操作，右栏其他部分仍然只读。

验收：
- [ ] 进入后，Bot 列表和 Bot 聊天隐藏，左侧窄条是任务对话，可以照常回复。
- [ ] 在评论框里按 Esc 只取消评论，不退出审阅模式。
- [ ] 窄窗口（768–1279px）下，审阅模式全屏，对话变成一个标签。

## P1

- **P1-1 终端抽屉：** 底部抽屉，⌘J 或 Ctrl+` 打开。只有任务所有者能输入，队友只读，不显示密钥文件。
  - 验收：所有者能在任务机器上执行命令；队友打开只能看输出。
- **P1-2 运行动作：** 「测试 / 构建 / 启动预览」来自仓库里的配置，输出进终端。
  - 验收：仓库配置了动作时按钮出现，没配置时不显示。
- **P1-3 预览标签：** 显示开发服务器的页面，做端口转发；桌面 App 可弹出成独立窗口。
  - 验收：启动预览后，「预览」标签显示页面，弹出的窗口和主窗口内容一致。
- **P1-4 撤销文件或块：** 在改动里撤销某个文件或某一块，撤销后改动刷新。
  - 验收：撤销的结果在 git 里可见，对话里有一条记录。

## P2

- 把代码还原到某一轮（每轮检查点）。
- Git 分支和提交面板。
- 输入框里用 @ 引用文件。
- 在线编辑源码。

## 不做

- 不加新的图标栏入口，不加新页面。
- 非代码任务不出现工作区。
- 手机上不做终端和编辑器。
