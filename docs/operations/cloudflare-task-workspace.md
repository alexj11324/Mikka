# Coding Task workspaces on Cloudflare

The product task Worker accepts Cloudflare service-binding calls. It has no public HTTP route. An authorized Mikka service supplies an owner, Workspace, Task, frozen canonical repository, Run, machine operation and expiring lease. Store provider choice at Run admission before binding production calls. The Worker trusts the service binding to enforce Mikka membership, consent and Run ownership. The repository's engineering GitHub Actions identity has no product access.

The owner, Workspace, Task and repository identify the Durable Object and its private R2 prefix. Each Run and operation forms a distinct writing lease. A status request leaves compute asleep. Repeated opens for a live lease reuse the same instance. A new operation cannot displace a live writer. Up to two task workspaces may use compute in this initial capacity pool. A lease may be renewed while live up to its original 15-minute hard deadline. A separate minute is reserved for checkpointing.

The Worker serializes its file and stop operations. It acknowledges a file write after the official Cloudflare SDK commits a checksum-bearing archive of the workspace directory to R2. Cold restore uses the SDK's integrity check and fails if the expected archive is unavailable. The runtime home and platform login files stay outside the backed-up directory. Repository-local credential stores are excluded. Backup pruning is limited to the current task's prefix and preserves the committed manifest.

Park persists the checkpoint before explicitly stopping compute and releasing capacity. A Durable Object alarm retries an interrupted cleanup. The restored container has a new process environment. The image uses the same native Claude Code and Codex installer and integrity pins as the Mikka daemon. CI verifies their binaries offline. Native subscription login, Git delivery, streaming, terminal and preview require the product Machine integration and its production acceptance.

For a deployment, provision a private R2 bucket and bind it as WORKSPACES, then wire only the authorized product host to the service. Keep the task Worker off public routes. The Eve host continues to own the public agent/session APIs and portable conversation scratch. See the current implementation/rollout evidence in [the product provider issue](https://github.com/alexj11324/Mikka/issues/1936).
