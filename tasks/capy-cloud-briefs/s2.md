# S2 新建任务只登记 + 指派唤醒 Bot
WIP：`wip/s2-new-task`（已改 lib/task-create-command.ts、task-create-only.ts、coordinator-events.ts，新增 lib/task-create-properties.ts、app/api/tasks/dictation/）。目标分支 `feat/s2-new-task-register-only`。决策：docs/design/decisions/2026-11-19-2110-new-task-create-only.md。
弹窗只登记（Capy issues.create 语义）：Environment 面包屑 · 标题（必填，Enter 提交）· 描述（@ 提及）· Status（默认 Todo）· Priority（默认 Normal）· Assignee（No assignee / People / Bots，可搜索单选）· Due date（Today / Tomorrow / End of this week / In one week）· Labels（可搜可建）· Access（Everyone / Only specific people，复用 resource_access_policies，加 setTaskVisibility）· 附件 · 语音听写（复用 lib/chat-attachments/transcribe.ts）· Create more（开：toast「Created MIKKA-xx」并清空；关：跳详情）。createOnlyCommand 加 assignee {kind:'user'|'bot', id}、dueDate、labelIds、visibility、files，数据沿用 lib/issue-metadata.ts。
指派唤醒：assignee_changed、评论、@ 提及 Bot 时往该 Bot 线程投「X assigned you MIKKA-xx」并触发一轮（参照 Capy issue_activity，复用 coordinator_events / mailbox 唤醒），Bot 自己决定是否派发。原弹窗的 Bot/Machine/Agent/Profile 与 Create and dispatch 移到任务详情「Start work」，沿用 dispatchTaskIntent。入口：页顶 New task + ⌘K。
UI：hosted-ui slots/new-task.tsx、slots/task-detail.tsx（affectUI）；公开默认版 components/coordinator/new-task-dialog.tsx。S1 在改状态选择器，复用它不改内部。测试含唤醒事件写入。
